# Мобильное приложение «Питомец Финни»

> Проект команды **404 ERROR** (Ученики МАОУ ДОК "Доминанта", корпус 2) в рамках хакатона **«Лидеры цифровой трансформации 2026»**.  
> **Задача №6:** «Мобильное приложение по повышению финансовой грамотности детей и молодежи Москвы» (Департамент финансов города Москвы).

---

## 1. Назначение продукта
«Питомец Финни» — интерактивный игровой тренажёр для детей 7–11 лет, формирующий навыки управления личным бюджетом на основе **Единой рамки компетенций в области финансовой грамотности (раздел 6)**.

Приложение обучает «Правилу 3 корзин» (Обязательные расходы, Необязательные желания, Накопления) через заботу о виртуальном питомце в безопасной игровой среде без реальных финансовых рисков.

## 3. Архитектура и стек технологий
* **Платформа:** Android 8.0+ (API level 26+).
* **Стек клиента:** Capacitor Android Runtime, WebView (HTML5 / CSS3 / Vanilla JS).
* **Звуковой движок:** Web Audio API (генерация звона монет и отклика поглаживания без внешних тяжелых медиафайлов).
* **Графика:** Векторная 2D-анимация (SVG) с системой эмоций, моргания и интерактивного поглаживания.
* **Хранилище:** Локальное клиентское хранилище (`localStorage`). Приложение полностью автономно и работает без подключения к Интернету (Offline-first).
* **Безопасность:** Нулевой сбор персональных данных (152-ФЗ РФ). Опасные разрешения (камера, микрофон, геолокация, контакты) отключены.

## 4. Сборка и запуск проекта

### Установка готового APK:
Файл релизной сборки находится в артефактах сборки GitHub Actions или в корне репозитория: `app-release.apk` (или `app-debug.apk`). Устанавливается на любое устройство Android 8.0+ без среды разработки.

### Сборка из исходного кода:
```bash
# 1. Установка зависимостей проекта
npm install

# 2. Синхронизация веб-ресурсов папки www с нативной частью Android
npx cap sync android

# 3. Сборка релизного APK через Gradle
cd android
./gradlew assembleRelease
# Собранный файл: android/app/build/outputs/apk/release/app-release.apk
