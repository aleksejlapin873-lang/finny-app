📌 О проекте
«Питомец Финни» — игровое мобильное приложение для детей 7–11 лет, формирующее базовые навыки управления личным бюджетом на основе Единой рамки компетенций в области финансовой грамотности и культуры (Минфин РФ / Банк России 2026).
В приложении ребенок заботится о питомце Финни, управляя ограниченным бюджетом через «Правило 3 корзин»:
Обязательные расходы (еда, уход, витамины);
Необязательные желания (игрушки, украшения, сладости);
Накопления (регулярные отчисления на долгосрочную цель — самокат/велосипед).

🛠 Технологический стек и архитектура
Клиент: Android 8.0+ (API 26+), Capacitor Android Platform, HTML5/CSS3/Vanilla JS (минимальный вес, высокий FPS 60 fps, запуск < 1.5 сек).
Хранение данных: Local Storage / IndexedDB (полная автономность, Offline-first режим без передачи данных во внешнюю сеть).
Безопасность: 0 опасных Android-разрешений (камера, контакты, микрофон, геолокация отключены). Нулевой сбор персональных данных (152-ФЗ РФ).

🚀 Инструкция по сборке и запуску
Запуск готового APK на физическом устройстве:
Скачайте релизный файл `app-release.apk` (или `app-debug.apk`) из папки `/build` или раздела Releases.
Установите на устройство под управлением Android 8.0 или новее.
Откройте приложение — демо-режим активирован по умолчанию.
Сборка из исходного кода:
```bash
# Клонирование репозитория
git clone https://github.com/your-team/pet-finny-lct2026.git
cd pet-finny-lct2026

# Синхронизация ассетов с Capacitor
npx cap sync android

# Сборка релизного APK через Gradle
cd android
./gradlew assembleRelease
# Готовый файл будет находиться в: app/build/outputs/apk/release/app-release.apk
```

👨‍💻 Экспертная проверка демонстрационного сценария (Приложение А ТЗ)
Шаг 1–3: Запустите приложение. Питомец Финни встречает вас в стартовом состоянии (Малыш).
Шаг 4–5: Нажмите «Составить план бюджета» на главном экране. Попробуйте превысить сумму лимита — приложение предупредит о перерасходе. Утвердите сбалансированный план.
Шаг 6: Откройте вкладку «Расходы». Попробуйте купить товар при нехватке монет — сработает обучающая подсказка без стресса. Купите обязательный корм 🥣 — шкала сытости вырастет.
Шаг 7: Перейдите во вкладку «Задания». Пройдите ситуации с правильным и ошибочным выбором — изучите понятные объяснения причинно-следственной связи.
Шаг 8: Нажмите «+ Отложить» в виджете копилки на главном экране и пополните копилку на самокат.
Шаг 9–10: Нажмите кнопку «СЛЕД. ПЕРИОД ⏩» в верхней плашке. Пройдите периоды 2, 3 и 4 — наблюдайте, как Финни растет до Подростка и Взрослого.
Шаг 11–12: Нажмите иконку 🛡️ в шапке, решите пример родительского контроля, ознакомьтесь со статистикой и протестируйте кнопку сброса тестового профиля.
